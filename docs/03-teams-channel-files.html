Teams Channel Files: Upload and Refresh

What the Demo Shows

  1. Unified App lists the teams and channels available to the signed-in user.
  2. Selecting a channel loads its shared files.
  3. The presenter uploads a file from Unified App.
  4. The file list refreshes automatically after the upload.
  5. Opening the same channel in Microsoft Teams shows the same file.

Microsoft Graph API Calls

All Graph paths use the base URL https://graph.microsoft.com.

  • GET /v1.0/me/joinedTeams?$select=displayName,id lists teams available to the signed-in user.
  • GET /v1.0/teams/{teamId}/channels lists channels for each team.
  • GET /v1.0/teams/{teamId}/photo/$value retrieves the team image.
  • GET /v1.0/groups/{teamId}/drive/root:/{channelName}:/children?$top={pageSize} lists files in the selected channel.
  • PUT /v1.0/groups/{teamId}/drive/root:/{channelName}/{fileName}:/content uploads a file to the channel's shared storage.
  • GET /v1.0/groups/{teamId}/drive/root:/{channelName}:/children?$top={pageSize} runs again after upload to refresh the React file list.
  • POST /v1.0/drives/{driveId}/items/{itemId}/preview returns the preview URL when the preview action is selected.

Why This Matters

Teams channel files are stored in SharePoint-backed channel storage. Unified App and Microsoft Teams work with the same shared content rather than creating separate copies.

Result: users can browse, preview, upload, and verify shared files without introducing another storage system.

Code Walkthrough

1. Select the team and channel

File: frontend/src/pages/TeamsPage.tsx

const getSelectedTeamChannel = (channelName, channelId) => {
  setSelectedTeamId(teamId);
  setSelectedChannelName(channelName);
  setSelectedChannelId(channelId);
};

Changing selectedTeamId and selectedChannelName updates the FileList properties and triggers a file reload.

2. Load files from the selected channel

File: frontend/src/MGTInternal/FileList/FileList.tsx

const endpoint = groupId
  ? `/groups/${groupId}/drive/root` +
    `${itemPath ? ':/' + itemPath + ':/children' : '/children'}`
  : `/me/drive/root/children`;

const result = await fetchFiles({
  accessToken,
  driveId: groupId || driveId,
  siteId,
  itemPath,
  pageSize,
});

setFiles(result);

3. Upload the selected file

File: frontend/src/MGTInternal/FileList/FileList.tsx

const endpoint = getUploadEndpoint({
  groupId,
  driveId,
  siteId,
  itemPath,
  file,
});

const client = getGraphClient(accessToken);
await client.api(endpoint).put(file);

4. Refresh after the upload

File: frontend/src/MGTInternal/FileList/FileList.tsx

for (const file of filesToUpload) {
  await client.api(endpoint).put(file);
}

loadFiles();

The refreshed Graph response updates React state, causing the new file to appear in the list.

Presenter Line

“Unified App uploads the file into the channel's shared storage and then refreshes the list. When I open the same channel in Microsoft Teams, the file is already there because both experiences use the same Microsoft 365 content.”
