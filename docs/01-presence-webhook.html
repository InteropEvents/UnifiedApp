Presence: Real-Time Updates with Webhooks

What the Demo Shows

  1. Unified App subscribes to presence changes for the signed-in user.
  2. The presenter changes presence in Microsoft Teams.
  3. Microsoft Graph pushes a notification to the public webhook.
  4. The backend relays that signal to the front end over WebSocket.
  5. Unified App retrieves the latest presence and updates without a refresh.

Microsoft Graph API Calls

All Graph paths use the base URL https://graph.microsoft.com.

  • GET /v1.0/subscriptions checks whether the presence subscription already exists.
  • POST /v1.0/subscriptions creates a subscription for /communications/presences/{userId}.
  • PATCH /v1.0/subscriptions/{subscriptionId} renews the subscription before it expires.
  • POST {notificationUrl} is the Graph webhook callback routed through the Dev Tunnel to /resourceNotifications.
  • GET /v1.0/me/presence retrieves the latest availability and activity after the notification arrives.

The presence change made in Microsoft Teams is Teams-managed; Unified App does not call Graph to make that change during this demo.

Why This Matters

This is a push-triggered model. Unified App does not continuously poll Microsoft Graph. Graph signals that something changed, and the application retrieves the current state only when needed.

Result: faster updates, fewer requests, and more reliable context for connected or agent-driven experiences.

Code Walkthrough

1. Create or renew the Graph subscription

File: frontend/src/services/graphPresenceService.tsx

const notificationUrl =
  `https://${process.env.REACT_APP_DOMAIN}/resourceNotifications`;
const expirationDateTime = new Date(
  Date.now() + 55 * 60 * 1000
).toISOString();

const existingSubscription = existingSubscriptions.value.find(
  sub => sub.resource === `/communications/presences/${userId}`
);

if (existingSubscription) {
  await client
    .api(`/subscriptions/${existingSubscription.id}`)
    .patch({ expirationDateTime });
  return;
}

await client.api('/subscriptions').post({
  changeType: 'updated',
  notificationUrl,
  resource: `/communications/presences/${userId}`,
  expirationDateTime,
  clientState: 'secretClientState',
});

2. Receive the webhook notification

File: backend/src/server.js

this.app.post(
  "/resourceNotifications",
  this.handleResourceNotifications.bind(this)
);

const notifications = req.body.value;
await NotificationService.handleNotifications(notifications);
res.status(200).send("Notification received");

3. Relay the notification

File: backend/services/notificationservice.js

async processNotification(notification) {
  WssSocketService.broadcast(JSON.stringify(notification));
}

4. Retrieve the current state and update the UI

File: frontend/src/MGTInternal/login/login.tsx

socket.onmessage = async event => {
  const data = JSON.parse(event.data);

  if (
    data.resource === `communications/presences('${userId}')` &&
    data.changeType === 'updated'
  ) {
    const latestPresence = await getUserPresence();
    setPresence(
      presenceMap[latestPresence ?? 'Offline'] ?? 'Offline'
    );
  }
};
