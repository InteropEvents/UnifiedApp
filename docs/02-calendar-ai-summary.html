Calendar: AI-Generated Meeting Summary

What the Demo Shows

  1. Unified App displays the signed-in user's meetings in a weekly agenda.
  2. The presenter selects Generate AI summary for Remote work strategy planning.
  3. The sample loads a synthetic transcript associated with that meeting.
  4. Azure OpenAI creates a structured summary.
  5. Unified App displays the result directly beneath the meeting.

Microsoft Graph API Calls

All Graph paths use the base URL https://graph.microsoft.com.

  • GET /v1.0/me/calendarview?$orderby=start/dateTime&startdatetime={start}&enddatetime={end} loads the selected week. Next week and Previous week change the date range and repeat this call.
  • GET /v1.0/users/{email}?$select=id resolves organizer and attendee identities for the agenda.
  • POST /v1.0/communications/getPresencesByUserId retrieves presence for the people shown on meeting cards.
  • GET /v1.0/users/{email}/photo/$value retrieves attendee photos.
  • POST /v1.0/me/calendar/events creates a meeting from the Calendar page.
  • PATCH /v1.0/me/calendar/events/{eventId} updates an existing meeting.

The AI request is not a Microsoft Graph call. The sample sends the transcript to POST https://{resource}.openai.azure.com/openai/deployments/{deployment}/chat/completions?api-version=2024-10-21.

Summary Structure

The prompt asks Azure OpenAI to return:

  • Summary
  • Decisions
  • Action items with owners and dates
  • Open questions

Result: a long meeting transcript becomes concise, actionable information inside the calendar workflow.

Code Walkthrough

1. Match the transcript to the meeting

File: frontend/src/MGTInternal/agenda/demoMeetingTranscript.ts

export function getDemoMeetingTranscript(
  subject: string
): string | undefined {
  const normalizedSubject = subject.trim().toLocaleLowerCase();

  return normalizedSubject ===
    DEMO_MEETING_SUBJECT.toLocaleLowerCase()
      ? DEMO_MEETING_TRANSCRIPT
      : undefined;
}

2. Request a structured AI summary

File: frontend/src/services/meetingSummaryService.ts

const response = await axios.post(
  getAzureOpenAIChatCompletionsUrl(),
  {
    messages: [
      {
        role: 'system',
        content:
          'Return sections named Summary, Decisions, ' +
          'Action items, and Open questions. Preserve ' +
          'stated owners and dates.',
      },
      {
        role: 'user',
        content:
          `Meeting: ${meetingSubject}\n\n${transcript}`,
      },
    ],
    temperature: 0.2,
    max_tokens: 800,
  },
  {
    headers: {
      'Content-Type': 'application/json',
      'api-key': apiKey,
    },
  }
);

3. Store and display the generated result

File: frontend/src/MGTInternal/agenda/Agenda.tsx

const transcript = getDemoMeetingTranscript(event.subject);
if (!transcript) return;

const summary = await summarizeMeetingTranscript(
  event.subject,
  transcript
);

setSummaries(current => ({
  ...current,
  [event.id]: summary,
}));

{summary && (
  <div className="agenda-summary-result" aria-live="polite">
    <strong>AI meeting summary</strong>
    <div>{summary}</div>
  </div>
)}
